# TXT文件处理器

一个基于Python的图形化工具，用于批量处理TXT文件并提取关键信息到Excel表格中。

## 🎯 功能特性

### 核心功能
- **批量文件处理**：自动扫描指定文件夹中的所有TXT文件
- **智能编码检测**：自动识别文件编码（支持UTF-8、GBK、GB18030、Big5等）
- **时间戳提取**：从文件末尾提取最后更新时间
- **订单号提取**：从"PlateA Assignments"区域提取订单号并去重
- **Excel集成**：直接读写Excel文件，支持多工作表
- **增量更新**：只更新发生变化的文件记录

### 智能处理
- **跳过机制**：自动跳过空文件、格式错误文件、编码错误文件
- **去重功能**：订单号自动去重，避免重复记录
- **格式标准化**：订单号统一格式（去除后缀，如`-0001`、`_0001`等）
- **错误处理**：完善的异常处理，确保程序稳定运行

## 🚀 使用方法

### 1. 启动程序
- 双击`TXT处理器_v5.exe`即可运行（无需安装Python环境）
- 或直接运行`python txt_processor.py`（需要Python环境）

### 2. 配置参数
1. **选择输入文件夹**：点击"选择输入文件夹"按钮，选择包含TXT文件的文件夹
2. **选择Excel文件**：点击"选择Excel文件"按钮，选择目标Excel文件
3. **选择工作表**：从下拉菜单中选择要操作的工作表名称
4. **选择文件编码**：建议选择"auto"自动检测，或手动指定编码格式

### 3. 开始处理
点击"开始处理"按钮，程序将：
- 扫描文件夹中的所有TXT文件
- 显示处理进度条
- 完成后弹出成功提示

## 🔧 技术特点

### 依赖库
- **tkinter**：图形用户界面
- **openpyxl**：Excel文件读写
- **chardet**：编码自动检测
- **json**：配置文件管理
- **os/datetime**：文件操作和时间处理

### 编码支持
- UTF-8（默认）
- GBK（简体中文）
- GB18030（扩展中文）
- Big5（繁体中文）
- 自动检测（推荐）

### 订单号提取规则
1. **定位区域**：在"PlateA Assignments"和"Protocol Path"之间
2. **提取位置**：每行第二列（制表符分隔）
3. **格式处理**：
   - 优先按`-`分割，取第一部分
   - 其次按`_`分割，取第一部分
   - 自动去除`-0001`、`_0001`等后缀
4. **去重处理**：相同订单号只保留一次

## 🔄 更新机制

### 增量更新逻辑
1. **文件存在检查**：检查文件名是否已存在于Excel中
2. **时间戳比对**：比较新旧时间戳是否一致
3. **订单号比对**：比较新旧订单号是否一致
4. **智能更新**：仅当数据发生变化时更新对应行

### 数据一致性
- 确保Excel数据与文件实际内容保持同步
- 避免重复添加相同记录
- 支持批量更新多个字段

## 🐛 常见问题

### Q: 程序无法识别某些TXT文件
**A**: 检查文件编码，尝试手动选择编码格式

### Q: 订单号提取不完整
**A**: 确认文件格式是否符合预期，检查"PlateA Assignments"区域

### Q: Excel文件被占用
**A**: 关闭Excel文件后再运行程序

### Q: 处理速度较慢
**A**: 减少单次处理的文件数量，或分批处理
